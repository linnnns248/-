# CityFlavors - 异地寻味

## UI Design Logic
- **Modern App Aesthetic**: Inspired by Meituan and Ele.me but with a more "Traveler First" editorial feel.
- **Dynamic Slot**: The center section adapts to the user's current city and time.
- **Vibrant Accent**: Using a warm 'Amber' and 'Sunset' color palette to stimulate appetite.

## Key Features
- **Time-Based Suggestions**: Breakfast / Lunch / Tea / Dinner / Late Night.
- **Local Specialty Badge**: Highlights "Hidden Gems" vs "Top Rated".
- **Interactive Carousel**: Swipe through local food stories.
